Frequently asked questions

Common questions about my design process and services.

What tools do you use for UI/UX design?

I primarily use Figma for UI/UX design, wireframing, and prototyping. I also use FigJam for user flows and brainstorming. For development, I work with HTML, CSS, JavaScript and Bootstrap.

Do you also develop the designs?

Yes, I convert my designs into responsive and functional websites using clean frontend code. This helps maintain design consistency from prototype to final product.

How do you approach a new project?

I start with understanding the user problem and project goals. Then I create user flows, wireframes, and high-fidelity UI designs. Finally, I test and refine the interface for better usability.
